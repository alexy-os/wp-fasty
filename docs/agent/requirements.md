# Requirements (current)

Source: user instructions in this project (2026-10-16), unless a link is given.

## Product vision
- wpfasty is a **theme configurator** (beyond Underscores/_s): an external client — web form, CLI or MCP tool
  (e.g. an IDE agent) — requests a site and downloads a **parent + child theme** with its own brand/style/tokens,
  selected post types and selected template engine (**Latte or Twig**).
- Output must be **wordpress.org-theme quality** so the downloader can improve it and publish to a marketplace.
  See [wporg-theme-review.md](wporg-theme-review.md) — note the plugin-territory conflict for custom post types.
- Reference themes in this repo (`themes/`): `latte` (parent), `latte-press` (standard blog, wp.org style),
  `latte-folio` (portfolio), `latte-shop` (shop: CPT product, cart, checkout, **no WooCommerce**). `latte-skin` = legacy minimal child example.

## Design rules (enforced by `bun run lint:design`, `tools/lint-design.ts`)
- **Spacing 8 + 4:** layout uses an 8px step (Tailwind spacing scale is 4px per unit, so layout uses even units:
  2, 4, 6, 8 … = 8, 16, 24, 32px). 4px steps (odd units 1, 3, 5 …) only *inside controls* (button, input, select,
  label, badge, textarea). No half steps (`*-0.5`, `*-1.5`) and no arbitrary px values (`p-[13px]`).
  *Lint status (verified 2026-10-16):* odd units outside controls, `*-N.5` half steps and `*-[Npx]` arbitrary px are errors.
- **Colors only via CSS variable tokens** (`--background`, `--foreground`, `--primary` …, shadcn-compatible names,
  see `themes/latte/assets/css/tokens.css`). No hex/rgb/hsl/oklch literals outside token files, no Tailwind palette classes.
- **Icons:** Lucide only (`lucide-static`, copied by `tools/icons.ts` into `themes/latte/assets/icons`, rendered via `{icon('name')}`).
  Lucide has no brand icons (github/linkedin/dribbble missing in lucide-static — verified 2026-10-16 by `tools/icons.ts`).
- **UI primitives:** UI8Kit primitives generated by `ui8kit/codegen` bricks (https://github.com/ui8kit/codegen,
  vendored at `packages/ui8kit-codegen`). Primitives print `children` unescaped → templates must pass captured
  (escaped) HTML, never raw data (lint rule "raw data passed as children").
- Customizer token editing: **postponed** by the user ("не важно сейчас").
